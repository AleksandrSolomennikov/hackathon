# Help science build better Parkinson's evaluation

*Predicting and correcting bias in motor score evaluation — for each visit, predict the unbiased (“true”) OFF MDS-UPDRS motor score.*

## Getting started

```bash
git clone git@github.com:probabl-ai/ibm-hackathon.git
cd ibm-hackathon
```

Then follow the guided lab: [GUIDED.md](docs/GUIDED.md).

## Documents

- [GUIDED.md](docs/GUIDED.md) - walkthrough: join Kaggle and form a team first, then setup, shared Exploratory Data Analysis (EDA), models, and Kaggle upload
- Kaggle competition: [ibm-probabl-hackathon](https://www.kaggle.com/t/ece2ca6a5b0b456b85692ad66a5aee6d)
